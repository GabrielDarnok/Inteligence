# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Shadow Intelligence, please report it responsibly.

**Do NOT open a public GitHub Issue for security vulnerabilities.**

Instead, send an email to **gabriel.silva@upx.com.br** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge your report within 48 hours and work with you to address the issue before any public disclosure.

## Scope

This policy applies to:
- The Shadow Intelligence web application and API
- The ingestion engine and connectors
- The database schema and access controls

## Supported Versions

| Version | Supported |
|---|---|
| Latest (`main` branch) | ✅ |
| Older commits | ❌ |

## Responsible Disclosure

We kindly ask that you:
- Allow us reasonable time to fix the issue before public disclosure
- Avoid accessing or modifying other users' data
- Act in good faith to avoid disruption to the service

Thank you for helping keep Shadow Intelligence secure.
